# 放課後等デイサービス Lino（リノ）LP

愛知県瀬戸市の放課後等デイサービス「Lino」（旧 HALO みんなの星）のランディングページです。

## 使い方

- このリポジトリの「Code」→「Download ZIP」でダウンロードし、解凍して `index.html` をブラウザで開くと表示できます
- 画像は `images/` フォルダに `IMAGE_GUIDE.md` 記載のファイル名で置くだけで自動的に表示されます

## 構成

- `index.html` — ページ本体
- `css/style.css` — デザイン
- `js/main.js` — メニュー・アニメーション等
- `images/` — 画像置き場（`concept/` はコンセプトPDFから抽出した仮素材）
- `IMAGE_GUIDE.md` — 追加してほしい画像の一覧（ファイル名・サイズ・生成プロンプト）
